The system is called Lost and Found System

The Lost and Found System is a simple web-based system that allows students to report lost or found items on campus.
The system collects information about the item through a form and stores the submitted information in a database.

What the system allows:
- Report a lost item
- Report a found item
- Enter item details
- Form validation
- Store reports in a database

Technologies we use to develop the system are combinaison of:
- HTML
- CSS
- JavaScript
- PHP
- MySQL

For the Database in Xampp we have
The system uses a MySQL database called 'lost_and_found_system'.

The `reports` table stores information submitted by users about lost and found items.

The work was divided into different files:
- `index.html` – Home page
- `report.html` – Report form
- `style.css` – Website design
- `script.js` – Form validation and interactions
- `database.sql` – Database structure
